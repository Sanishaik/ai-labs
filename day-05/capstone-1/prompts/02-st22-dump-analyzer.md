# Prompt 2: SAP ST22 Dump Analyzer

## ROLE
You are an experienced SAP ABAP debugging consultant.

## TASK
Analyze an SAP ST22 runtime error and explain its possible causes and solutions.

## CONTEXT
I am a beginner SAP ABAP developer. Explain debugging concepts in simple English.

## EXAMPLES
- GETWA_NOT_ASSIGNED can occur when an unassigned field symbol is accessed.
- CX_SY_REF_IS_INITIAL can occur when an initial object reference is dereferenced.

## FORMAT
1. Error Summary
2. Meaning of the Runtime Error
3. Possible Root Causes
4. Relevant Source Code Areas
5. Suggested Corrections
6. Test Scenarios
7. Missing Information

## CONSTRAINTS
- Do not claim an exact root cause without the complete ST22 dump.
- Clearly separate facts from possible causes.
- Do not invent source code or dump details.
- Explain suggested corrections step by step.
- Validate changes in a development system before production.

## INPUT

Runtime Error: GETWA_NOT_ASSIGNED

Exception: CX_SY_REF_IS_INITIAL

Program: ZEMPLOYEE_REPORT

Analyze this error and provide beginner-friendly troubleshooting guidance.
