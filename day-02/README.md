## RTCEFC Framework

I used the following six building blocks to create effective prompts:

1. **Role:** Defines who the AI should act as.
2. **Task:** Clearly states what the AI needs to do.
3. **Context:** Provides relevant background information.
4. **Example:** Gives an example or practical scenario.
5. **Format:** Specifies how the answer should be presented.
6. **Constraints:** Defines rules, limits, and requirements.

## Prompts Tested

I practised prompt engineering using five topics:

- SAP ABAP program development
- SAP RAP
- SAP BTP
- SAP OData

For each topic, I compared a vague original prompt with an improved prompt using RTCEFC.

## What I Learned

- Vague prompts can produce general answers that may not meet specific requirements.
- Clear roles and tasks help the AI understand what is expected.
- Context and examples make responses more relevant to the user's needs.
- Output formats and constraints help produce organized, focused answers.
- Reviewing and scoring prompts helps identify opportunities for improvement.

## Conclusion

This exercise helped me understand how to create, review, and improve prompts using the RTCEFC framework. I learned that well-structured prompts can produce more relevant and organized responses when the instructions and context are clear.
