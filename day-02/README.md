# Day 2 — Prompt Engineering

## Objective
Learn how to write effective prompts using six building blocks: Role, Task, Context, Examples, Format, and Constraints.

## Tasks
1. Fix 5 bad prompts and save before-and-after pairs in `prompts.md`.
2. Test 10 SAP tasks using three prompt versions and record scores in `scores.csv`.
3. Reconstruct prompts from three AI answers and save them in `reverse-engineering.md`.
4. Create a prompt reviewer and test it on five bad prompts in `reviewer.md`.
5. Record completed work and explain the best prompt in `lab-log.md`.

## Files
- `prompts.md` — Five before-and-after prompt pairs.
- `scores.csv` — Scores for 30 AI answers.
- `reverse-engineering.md` — Three reconstructed prompts.
- `reviewer.md` — Prompt reviewer and five test runs.
- `lab-log.md` — Daily work summary.

## Learning Outcome
Understand how structured prompts can improve the relevance, clarity, and format of AI responses.
